# 교실 도구 Google Drive · Vercel 버전 1.13

GitHub 저장소를 코드 원본으로 사용하고, Vercel에서 앱과 OAuth 백엔드를 함께 실행하는 버전입니다. Google Drive 자료는 기존처럼 사용자의 Drive에 저장됩니다. Vercel에는 수업 자료를 저장하지 않습니다.

## 로그인 유지 방식

- Google 인증 코드는 Vercel API에서 교환합니다.
- 갱신 토큰은 암호화된 `HttpOnly; Secure; SameSite=Lax` 쿠키로 저장합니다. 자바스크립트가 토큰을 읽을 수 없습니다.
- 새로고침하면 서버가 쿠키를 확인해 Drive 접속을 이어갑니다.
- `연결 해제`를 누르면 Google 권한을 취소하고 브라우저 세션 쿠키를 지웁니다.
- Google에서 권한을 취소하거나 계정 보안 정책으로 토큰이 만료되면 다시 로그인해야 합니다.

## 1. GitHub에 업로드

1. 압축을 풉니다.
2. 압축 안의 `google` 폴더 내용을 GitHub 저장소의 기존 `google/`에 덮어씁니다.
3. 커밋합니다. v1.13은 `index.html`, `api/google-proxy.js`, `api/drive-upload.js`를 함께 교체합니다. 압축의 google 폴더 전체를 기존 google 폴더에 덮어쓰면 됩니다. 기존 API 파일과 환경 변수는 유지합니다.

## 2. Vercel 프로젝트 연결

1. Vercel에서 **Add New → Project**를 선택하고 해당 GitHub 저장소를 연결합니다.
2. **Root Directory**를 `google`로 지정합니다.
3. Framework Preset은 Other로 둡니다. 빌드 명령과 Output Directory는 비워 둡니다.
4. Vercel이 정적 페이지와 `api/` 폴더의 서버리스 함수를 배포합니다.
5. 첫 배포 후 사용할 고정 도메인(예: `https://교실도구이름.vercel.app`)을 확인합니다. 이후 환경 변수의 `APP_ORIGIN`에는 이 주소를 사용합니다.

## 3. Google Cloud OAuth 설정

기존 OAuth 웹 클라이언트를 사용해도 됩니다.

- **승인된 JavaScript 원본**에 Vercel 도메인을 추가합니다. 예: `https://교실도구이름.vercel.app`
- **승인된 리디렉션 URI**에 다음 주소를 추가합니다. 예: `https://교실도구이름.vercel.app/api/auth/callback`
- 클라이언트 ID와 클라이언트 보안 비밀번호(Secret)를 준비합니다. Secret은 HTML이나 GitHub에 넣지 않습니다.
- Drive API 사용 설정과 OAuth 동의 화면의 `drive.file` 권한 설정은 기존 설정을 유지합니다.

## 4. Vercel 환경 변수

Vercel 프로젝트 **Settings → Environment Variables**에 Production 환경으로 등록합니다.

| 이름 | 값 |
| --- | --- |
| `APP_ORIGIN` | `https://교실도구이름.vercel.app` (끝에 `/` 없음) |
| `GOOGLE_CLIENT_ID` | Google OAuth 웹 클라이언트 ID |
| `GOOGLE_CLIENT_SECRET` | Google Cloud에서 해당 웹 클라이언트의 보안 비밀번호 |
| `GOOGLE_REDIRECT_URI` | `https://교실도구이름.vercel.app/api/auth/callback` |
| `SESSION_ENCRYPTION_KEY` | 아래 명령으로 만든 무작위 32바이트 키를 Base64 문자열로 입력 |

Mac 터미널에서 `openssl rand -base64 32`를 실행해 키를 만들 수 있습니다. 출력된 값을 Vercel에만 입력하고 GitHub나 채팅에 올리지 마세요. 환경 변수 저장 후 **Redeploy**해야 적용됩니다.

## 5. 사용

Vercel 배포 주소를 열고 Google 계정으로 한 번 로그인합니다. 이후 새로고침해도 로그인 세션이 유지됩니다. Google Drive 상단 버튼에 연결된 이메일이 표시되고, 기기에는 먼저 저장하고, 마지막 변경으로부터 10초 뒤 Google Drive에 자동 저장합니다. 그 사이 다시 변경하면 10초를 새로 기다립니다. 더보기의 저장 버튼은 즉시 저장합니다. Google Drive의 파일은 `ClassroomAllInOne/classroom-all-in-one-data.json`입니다.

GitHub Pages의 기존 주소는 정적 버전으로 남습니다. 로그인 유지 기능을 쓰려면 앱을 Vercel 배포 주소에서 열어야 합니다.

## 보안 참고

- OAuth Client ID는 공개 식별자지만 Client Secret과 세션 암호화 키는 서버 환경 변수에만 둡니다.
- refresh token은 암호화된 HttpOnly 보안 쿠키로 저장합니다. 브라우저 쿠키를 지우거나 Google 권한을 취소하면 다시 로그인해야 합니다.
- Vercel 미리보기 주소는 OAuth에 등록되지 않을 수 있으므로 Production 도메인으로 로그인 테스트를 하세요.

## v1.07 변경 사항

- 프로크리에이트처럼 왼쪽에 펜 크기와 투명도 세로 슬라이더를 배치했습니다. 폭은 34px로 좁게 만들고, 설명 글자 없이 `px`와 `%` 값만 표시합니다. 크기는 1~50px입니다. 100%가 가장 진하며 형광펜은 기본 투명도에 이 값을 적용합니다.
- `⋯ 더보기 → 이미지 자르기` 또는 사진 선택 후 `이미지 자르기` 체크박스로 사진/PDF에서 남길 부분을 드래그합니다. 이 모드에서는 모서리 드래그로 크기를 조절하지 않습니다. 원본 이미지 데이터를 유지하며 실행 취소와 `자르기 되돌리기`를 지원합니다.
- PDF 가져오기에서 `한 쪽 + 오른쪽 빈 필기 공간`과 `두 쪽씩 나란히`를 선택합니다. 두 쪽 보기는 선택한 순서대로 묶고, 홀수로 남으면 오른쪽을 비웁니다. 이전/다음 버튼도 묶음 단위로 이동합니다.
- 여러 묶음은 선택한 가로/세로 방향으로 같은 시트에 배치합니다.
- 배경 설정의 크기 제한은 왼쪽/오른쪽/위쪽/아래쪽 체크박스로 바꿨습니다. 한 쪽 PDF는 기본적으로 오른쪽 제한을 해제합니다. 위/아래는 현재 펼친 PDF 높이, 왼쪽은 교과서 왼쪽 테두리가 기준입니다. 두 쪽 보기는 네 방향을 기본 제한합니다.
- 이전 형식의 보드 제한은 방향별 설정으로 변환합니다. 기존에 가져온 PDF는 다시 가져올 때 새 보기 방식으로 배치됩니다.
- 업데이트할 파일은 `google/index.html`입니다.

## v1.08 이미지 자르기 수정

- 사진/PDF 선택 후 이미지 자르기를 켜면 모서리 4개와 변 가운데 4개 조절점이 나타납니다.
- 조절점을 안쪽/바깥쪽으로 움직여 남길 범위를 정합니다. 테두리 안쪽을 끌면 범위를 이동합니다. 이미지 자체를 늘이거나 줄이지 않습니다.
- 제외될 부분은 어둡게 표시되며, 하단의 자르기 적용으로 확정합니다. 취소하면 편집 전 상태를 유지합니다.
- 다시 자르기를 켜면 원본 범위까지 넓힐 수 있습니다. 원본 전체 선택 후 적용하면 자르기를 해제합니다. 실행 취소/다시 실행과 저장 후 복원도 지원합니다.
- 업데이트할 파일은 google/index.html입니다.

## v1.09 페이지 정렬과 PDF 가져오기

- 하단 쪽 탭을 손가락/마우스로 끌어 순서를 바꿉니다. 끝으로 끌면 자동으로 스크롤합니다. 선택 중인 쪽과 쪽의 내용은 유지하며 실행 취소/자동 저장을 지원합니다. 키보드는 Alt+왼쪽/오른쪽 화살표를 지원합니다.
- PDF 파일 선택에서 여러 파일을 동시에 고릅니다. 목록에서 ↑↓로 순서를 바꾸고 ×로 제외할 수 있습니다. 여러 파일은 각각 쪽 범위를 정할 수 있습니다.
- 새 페이지에 pdf 가져오기: PDF 파일마다 새 화이트보드 페이지를 만듭니다.
- 현재 페이지에 pdf 가져오기: 기존 자료를 유지하고, 선택한 방향으로 기존 내용 뒤에 이어 붙입니다. PDF 쪽 넘기기로 기존/새 PDF를 오갈 수 있습니다.
- 파일 하나씩 처리하며, 모든 변환이 끝난 뒤 반영하므로 취소/변환 오류 시 기존 수업 자료가 바뀌지 않습니다.
- 업데이트할 파일은 google/index.html입니다.

## v1.10 PDF 열기 오류 수정

- PDF 처리 자료를 하나의 긴 JSON 태그 대신 32KB 단위의 작은 데이터 태그로 나눠 저장합니다. 외부 서버에서 PDF 엔진을 내려받지 않으므로 기존 오프라인 처리를 유지합니다.
- 조각 수·전체 길이·SHA-256을 확인하여 누락되거나 손상된 자료를 감지합니다. 오류가 발생하면 새로고침 또는 파일 교체 안내를 표시하며 다시 시도할 수 있습니다.
- 페이지 드래그 정렬, 여러 PDF 선택, 새/현재 페이지 가져오기는 유지합니다.
- 업데이트할 파일은 google/index.html입니다.

### PDF 파일 목록 사용

- 파일 추가를 여러 번 눌러 기존 목록에 PDF를 더합니다. 파일을 창으로 끌어 넣어도 됩니다.
- PDF마다 파일명·전체 쪽수와 별도의 가져올 쪽 입력칸이 표시됩니다. 예: ~3, 4~, 2, 5~8. 빈칸이면 해당 PDF 전체입니다.
- ↑↓로 파일 순서를 정하고 ×로 하나씩 제외하거나 전체 비우기를 사용합니다. 순서를 바꿔도 각 파일의 쪽 범위는 유지됩니다.

## v1.11 글자·LaTeX·저장 메뉴

- T 글자 입력창에 LaTeX 체크박스, 글자 색, 글자 크기와 실시간 미리보기를 추가했습니다. 체크하지 않으면 일반 글자로 표시합니다.
- LaTeX는 MathJax 3.2.2로 수학 표현식을 SVG로 변환합니다. 수식 처리 코드를 HTML 안에 32KB 조각으로 넣어 수식 표시 자체에는 외부 다운로드가 필요하지 않습니다. 전체 LaTeX 문서의 조판 기능은 포함하지 않습니다.
- 분수, 근호, 위·아래 첨자, 벡터, 합, 적분, 행렬 등 수식을 지원합니다. 원본 LaTeX와 벡터 그림을 함께 저장하며 확대·PNG 저장·백업/복원에도 표시됩니다.
- 올가미로 글자 하나를 선택한 뒤 글자 편집을 누르면 내용·색·크기·LaTeX 체크 여부를 바꿀 수 있습니다. 취소, 실행 취소/다시 실행, 복사/붙여넣기도 지원합니다.
- 상단 색상 도구를 펜 등 도구 버튼 바로 옆에 붙였습니다.
- 더보기에서 저장 버튼, Google 로그인 이메일, Drive 저장 대기/저장 중/저장 완료/오류 상태와 기기 저장 상태를 확인합니다. 명시적 저장은 기기 저장을 완료한 뒤 Drive에 최신 내용을 저장합니다. 업로드 도중 바뀐 내용도 순서대로 저장합니다.
- 기존 Google OAuth/Vercel 환경 변수와 API 파일은 그대로 사용합니다. 업데이트할 파일은 google/index.html입니다.

## v1.12 Drive 업로드와 자동 저장 수정

- 브라우저에서 Google 업로드 주소로 직접 전송하던 과정을 같은 사이트의 `/api/drive-upload`로 옮겼습니다. Google 토큰은 기존과 같이 서버에서만 사용합니다.
- 큰 PDF/이미지가 든 자료는 2MiB씩 전송합니다. JSON 전송 크기도 Vercel 요청 제한보다 작게 유지합니다. 마지막 조각의 Google 저장 확인 응답을 받은 뒤에만 저장 완료로 표시합니다.
- 일시적인 전송 장애에는 최대 두 번 재시도합니다. 재시도 전 Google에 받은 위치를 확인하여 이미 받은 조각을 중복 전송하지 않습니다.
- 변경한 자료를 먼저 기기에 저장하고 마지막 변경 10초 후 Drive에 저장합니다. 추가 변경 시 대기 시간을 다시 계산합니다. 자동 업로드 중 새로 바뀐 내용도 마지막 변경 후 10초가 지나면 저장합니다.
- 더보기의 저장 버튼은 10초를 기다리지 않습니다. 기기 저장을 먼저 완료하고 Drive로 보내며, 수동 업로드 중 바뀐 내용도 순서대로 저장합니다.
- 오류가 나도 기기에 저장한 자료는 유지합니다. 기기 저장 상태와 Drive 저장 상태는 각각 표시합니다.
- **업데이트 파일: `google/index.html`, `google/api/drive-upload.js`(신규). 압축의 google 폴더 전체를 기존 google 폴더에 덮어쓰는 것을 권장합니다.** README도 최신 안내로 바꿨습니다.
- 기존 Vercel 환경 변수와 Google OAuth 설정은 바꾸지 않습니다. GitHub 커밋 후 Vercel의 새 배포가 완료되어야 저장 API도 적용됩니다.

- 실행 취소·다시 실행·사진·배경·더보기 버튼을 오른쪽에 모았습니다. 넓게 쓰기에서 화면이 좁으면 왼쪽 도구 부분을 좌우로 스크롤하며 오른쪽 버튼과 도구로 돌아가기는 계속 보입니다.
- Drive 저장을 확인하지 못한 기기 자료가 있으면 새로고침 시 오래된 Drive 자료로 자동 교체하지 않고 사용할 자료를 선택하게 합니다. 이전 버전에서 넘어올 때도 기존 필기가 있으면 먼저 선택합니다.

## v1.13 쪽별·이미지별 저장 최적화

- PDF에서 가져온 페이지 이미지와 사진은 SHA-256으로 구분하여 별도 원본 파일로 한 번만 업로드합니다. 같은 원본을 여러 쪽에서 사용해도 공유합니다.
- 각 화이트보드 쪽은 원본의 파일 번호와 필기·글자·크기·위치·자르기·배경·PDF 쪽 넘김 정보를 담은 작은 JSON으로 저장합니다. 변경된 쪽만 새로 저장합니다.
- 모든 쪽의 순서와 수업 설정을 담은 작은 목록을 마지막에 저장합니다. 원본·쪽 저장 도중 실패해도 직전에 완료된 목록은 유지됩니다. 다음 저장 때 이미 업로드한 파일을 재사용합니다.
- 내용이 같으면 저장 버튼을 눌러도 원본·쪽·목록을 재전송하지 않습니다. 자동 저장은 마지막 변경 10초 후, 저장 버튼은 즉시 실행합니다.
- 사진/PDF의 이동·크기 변경·자르기는 숫자 정보만 저장합니다. 필기를 바꿔도 PDF 이미지를 다시 보내지 않습니다. 새 원본이 있을 때만 큰 전송이 발생합니다.
- 사용하지 않는 원본과 이전 쪽 데이터는 새 목록의 저장 확인 후 Drive에서 삭제합니다. 다른 쪽에서 공유하는 원본은 유지합니다. 정리는 앱이 만든 전용 파일에만 적용하며 사용자 Drive의 다른 파일은 건드리지 않습니다.
- 삭제 원본은 해당 기기의 IndexedDB 캐시에 남겨 두고 현재 작업의 실행 취소에 사용합니다. 실행 취소로 원본을 복원하면 다음 저장 때 필요한 원본을 다시 올립니다. 기기 보관이 확인되지 않으면 Drive 원본 정리를 보류하고 상태에 표시합니다.
- 실행 취소 이력은 현재 열린 작업 범위입니다. 다른 기기나 새로고침 후에는 삭제된 내용을 실행 취소할 수 없습니다. 전체 백업은 현재 사용하는 모든 쪽과 원본을 포함하며, 삭제 이력은 포함하지 않습니다.
- 다른 기기에서 불러오면 목록·쪽·원본을 조합해 복원합니다. 한 번 받은 원본과 쪽은 기기에 캐시하여 이후 재사용합니다. 원본은 2MiB 범위로 나눠 받으며 해시로 손상을 검사합니다. 불러오기 전체를 검사한 뒤에만 현재 자료를 교체합니다.
- v1.12까지의 통합 JSON 자료는 그대로 읽습니다. v1.13에서 처음 저장할 때 새 방식으로 변환합니다. 첫 저장·새 PDF 추가는 원본 전송이 필요하므로 시간이 걸릴 수 있습니다. 이후 저장이 가벼워집니다.
- **예전 앱으로 새 Drive 목록을 열 수 없으므로, 번갈아 사용하는 기기 모두 v1.13 주소에서 새로고침한 뒤 사용하세요.** 환경 변수와 Google 권한 설정은 바꾸지 않습니다.

### 전체 화면의 저장 표시와 전체 백업

- 교실 도구 제목 오른쪽에 Drive 저장 대기·저장 중·저장 완료와 마지막 저장 시간을 작게 표시합니다. 실패는 붉게 표시합니다.
- 상단 `✓ 저장` 버튼은 어느 도구에서든 현재 앱 자료와 화이트보드 전체를 저장합니다. 넓게 쓰기에서는 기존 `⋯ 더보기 → 저장`을 사용합니다.
- `설정 → 전체 백업 다운로드`는 모든 반, 수업 설정, 화이트보드의 모든 쪽, PDF 페이지 이미지와 사진, 필기, 글자·수식을 하나의 독립 JSON 파일에 포함합니다. Drive 파일이 없어도 이 백업을 복원할 수 있습니다.
- 백업 복원 시 화이트보드를 포함한 자료를 먼저 검사합니다. 백업 파일에 화이트보드가 없는 이전 형식은 현재 화이트보드를 유지합니다.

업데이트 파일: `google/index.html`, `google/api/google-proxy.js`, `google/api/drive-upload.js`, `google/README.md`. 압축의 **google 폴더 전체**를 기존 google 폴더에 덮어쓰고 커밋한 뒤 Vercel 배포 완료를 기다립니다.
