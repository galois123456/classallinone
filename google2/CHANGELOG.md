## 1.05 · 2026-11-05

학생 누가기록 → 전체 보기 → 날짜별 보기에서 수정 오른쪽에 빨간색 삭제 버튼을 추가했습니다.
기존 삭제 확인창을 거쳐 해당 기록만 삭제합니다. 취소하면 자료를 유지합니다.
삭제 후 전체 보기와 기본 목록의 기록 건수, 날짜별 목록, 참고자료, 학생별 건수가 바로 갱신됩니다. 전체 보기 창은 열린 상태를 유지합니다.
기존 수정 기능과 저장 경로를 사용하며, 다른 학생·반의 누가기록과 스탬프 자료는 유지됩니다.

## 1.04 · 2026-10-20

생기부 작성 도우미 구글 ver1.04

개별 안내장 표를 요청한 구조로 변경했습니다. 왼쪽 ‘수행평가’ 세로 셀을 수행평가별 행과 수행평가 총점 행에 걸쳐 묶고, 1회고사·2회고사·학기말 점수를 아래에 배치합니다.
수행평가 총점과 학기말 점수 행은 회색으로 강조합니다. 인쇄 선택에 따라 실제 선택한 점수만 표시하며, 지필평가의 객관식·논서술형 상세 점수도 유지합니다.
최종 반영 비율 합계가 100%를 넘으면 입력 중에도 빨간 경고가 표시됩니다. 다른 평가 비율이 비어 있어도 입력한 비율 합계가 100%를 넘으면 경고합니다. 100% 이하로 수정하면 초과 경고가 사라집니다.
비율 미설정 또는 100% 미만일 때는 기존처럼 경고를 표시하지 않습니다. 학기말 점수와 학기말 인쇄는 모든 평가 비율의 합계가 100%일 때 사용할 수 있습니다.
전체명단의 기본 A4 세로 25명 한 장 인쇄와 iPad 계정 표시, 기존 원점수 가중 계산식은 유지합니다.

기존 폴더의 파일을 덮어쓰고 배포하세요. 추가 SQL·환경변수 변경은 없습니다.
